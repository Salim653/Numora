# API modules

Create business modules here as feature work begins. The approved capability boundaries are documented in `docs/architecture/MODULE_BOUNDARIES.md`.

See `docs/development/PROJECT_STRUCTURE.md` from the repository root for the team-wide folder guide and current-versus-planned paths.

Expected modules include Identity, Schools, Classes, Content, Assessments, Progress, Tryouts, Leaderboards, PvP, Monitoring, Feedback, Reports, Videos, Admin, Analytics, IRT, and Audit.

Do not pre-create empty services/controllers or combine unrelated domains into a generic `common`/`services` module.
