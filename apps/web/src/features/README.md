# Web feature modules

Product UI code should be grouped by capability/role rather than a single global components directory. Shared accessible primitives belong in `packages/ui`.

See `docs/development/PROJECT_STRUCTURE.md` from the repository root for the team-wide folder guide and current-versus-planned paths.

Initial feature areas will include onboarding/identity, core learning, monitoring, admin/content, leaderboard, and PvP. Do not put backend business rules into React components.
