Demo draft tetap diberi label dan memerlukan review Curriculum sebelum trial. Tes memeriksa 503, rollback, dan hasil lama yang tetap sama setelah sumber diarsipkan. |

## Gate GitHub

Pemeriksaan ruleset langsung menunjukkan `main` protected, minimal satu approval serta code-owner review diwajibkan. Akun CLI dan connector sama-sama `splakplutoy`, penulis PR #17; akun penulis tidak dapat memenuhi approval independen. Reviewer lain yang mencakup perubahan lintas path perlu memberi approval sesuai `.github/CODEOWNERS` (antara lain `ayiinee` untuk backend/shared dan `a-ali-wafa` untuk onboarding). Tidak ada perubahan aturan proteksi atau penggunaan admin bypass dalam review ini.

Review engineering dan CI bukan pengganti approval code owner. Status merge final harus diperiksa pada PR #17; sampai approval yang diwajibkan tersedia, `main` tidak boleh dianggap sudah menerima perbaikan.
